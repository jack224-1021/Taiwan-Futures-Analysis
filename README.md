## 🌟 系統亮點與五大核心模組

### 1. 🏆 全市場個股期貨強勢 / 弱勢排名總榜 (Ranking Engine)
- **硬性濾網**：自動剔除近 5 日期貨均量 < 500口、現貨成交值 < 1億、未站上 20MA/60MA 或正乖離 > 15%（標記過熱）之標的，並排除處置與全額交割股。
- **五大維度評分 (滿分 100 分)**：
  - **A. 趨勢結構 (25%)**：多頭均線排列 (現價 > 5MA > 10MA > 20MA > 60MA)、創 52 週新高。
  - **B. 相對強度 RS (25%)**：全市場百分位 PR 值、超越大盤超額報酬 (Alpha)。
  - **C. 動能指標 (15%)**：ADX(14) > 25、MACD 柱狀體擴張、RSI(14) 55~80 健康區間。
  - **D. 量價與波動 (15%)**：當日量比 ≥ 1.5、價漲量增、VCP 波動收斂突破。
  - **E. 籌碼與未平倉量 OI (20%)**：三大法人連續買超、**價漲 + 期貨 OI 增加（多方增倉最強訊號）**。
  - **基本面加成**：連續 3 個月營收年增 > 20% 加 5~10 分。
- **雙向模式**：一鍵切換「📈 多方強勢榜」與「📉 空方弱勢榜」。

### 2. 💼 庫存部位盤中即時決策監控 (Intraday Portfolio Monitor)
- **盤中每 N 秒自動刷新**：計算現價、未實現損益（NT$ 與 %）、目前賺取之 R 倍數。
- **四大訊號燈決策系統**：
  - 🟢 **續抱**：站穩 20MA 與 VWAP，未破停損線，多頭結構完整。
  - 🔵 **可加碼**：回測 VWAP / 支撐不破並放量再攻，整體 R:R 仍合格。
  - 🟡 **減碼 / 上移停損**：已達 1.5R~2R 獲利目標，分批落袋並將停損上移至成本價（保本防護）。
  - 🔴 **立即出場**：跌破設定停損點或放量跌破關鍵均線。
- **結算日轉倉提醒**：倒數台指期每月第三個週三結算日，提前預警轉倉風險。

### 3. 🎯 交易計畫與風控部位試算機 (Trade Planner)
- **精準跳動點修正**：依台股最小跳動點（Tick Size: <10→0.01, 10-50→0.05, 50-100→0.1, 100-500→0.5, 500-1000→1.0, >1000→5.0）校正進場、停損與停利點。
- **點位自動生成**：
  - 建議進場價（突破價 + 1 Tick）
  - 波動停損價（進場價 - 1.5 × ATR(14)）
  - 1R / 2R / 3R 階梯目標價
  - 風險報酬比 R:R 門檻防護（R:R < 1.5 標記警示）
- **專業部位管理**：依「單筆最大風險 1%（如 NT$ 10,000）」反推建議下單口數，嚴格限制總保證金使用率 ≤ 50%。

### 4. 📰 重大訊息與財經新聞 AI 情緒雷達
- 即時對接 MOPS 重大訊息與財經即時新聞。
- 自動標記 🟢 利多、🔴 利空、⚪ 中性 與事件類型（營收創高、法說會、擴產、處置注意）。

### 5. ⚙️ 集中化設定檔 (config.yaml)
- 所有權重、門檻、風控參數統一存放於 [config.yaml](file:///d:/00.GEMINI%E5%8D%94%E4%BD%9C/%E8%82%A1%E6%9C%9F%E5%88%86%E6%9E%90%E8%BB%9F%E9%AB%94%E9%96%8B%E7%99%BC/config.yaml)，無硬編碼。

## 🚀 快速啟動與操作指南

1. **直接啟動終端**：
   - 雙擊開啟 [index.html](file:///d:/00.GEMINI%E5%8D%94%E4%BD%9C/%E8%82%A1%E6%9C%9F%E5%88%86%E6%9E%90%E8%BB%9F%E9%AB%94%E9%96%8B%E7%99%BC/index.html) 即可在瀏覽器中操作完整終端介面。
2. **操作體驗流程**：
   - **Step 1**：在【強勢排名總榜】查看即時多方/空方排名、總分與加減分解析。
   - **Step 2**：點擊任一標的之「🎯 擬定計畫」，跳轉至【交易計畫與風控】，即時查看停損價、1R~3R 目標價、建議下單口數與保證金。
   - **Step 3**：點擊「➕ 將本交易計畫加入庫存即時監控」，切換至【庫存盤中監控】體驗即時損益、賺取 R 倍數與四色訊號燈！
